# pi-qdash historical repository

Active development and releases live in [QDash](https://github.com/oqtopus-team/qdash/tree/develop/packages/pi-qdash).
Open feature, bug-fix, and documentation pull requests against QDash's `develop` branch.
This repository retains the earlier source, tags, and changelog for provenance.

## Final transition changes

- Use a pull request; do not push directly to `main`.
- Keep historical source and releases intact.
- Do not publish to npm or create new release tags here. QDash owns the `latest` and `beta` channels.
- See the [QDash package guide](https://oqtopus-team.github.io/qdash/developer-guide/copilot/packages) for current setup, checks, and releases.
